# Gate 9 execution plan / closure criteria

Gate 9 closes locally only when all of the following are true on one frozen source identity:

1. signed `.odparms` verification and Score→IR byte-for-byte recompilation pass;
2. exact PCM is bound to `analysis.bin` and soundtrack padding is digital zero;
3. reference video frames and frame-root are deterministic;
4. deterministic work quote equals observed work;
5. transactional sink failure/cancellation proves no partial commit or caller receipt;
6. Render Receipt canonicality, timeline, work quote and render_id are self-recomputed and independently reconstructed;
7. controller Ed25519 signature is independently verified;
8. strict GCC and Clang, ASan+UBSan in both, TSan, GCC analyzer and 3/3 reproducibility pass;
9. Music Spine reports the Gate 9 modules/invariants/capabilities/output profile honestly;
10. a source-bound evidence receipt and reproducible checkpoint ZIP are emitted.

Actual cloud deployment remains a separate runtime lane and is not upgraded to PASS by local success.
